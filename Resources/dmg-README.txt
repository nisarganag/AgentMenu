AgentMenu
=========

1. Drag AgentMenu.app into the Applications folder.

2. The first launch will be blocked with "cannot be opened because the
   developer cannot be verified". This app is ad-hoc signed rather than
   notarised (notarisation requires a paid Apple Developer ID).

   To open it the first time:
      Right-click AgentMenu.app  ->  Open  ->  Open

   Only needed once.

3. AgentMenu lives in the menu bar. Open it and use Preferences to enable
   "Start at login" and to install the permission-detection hooks.

Note: AgentMenu must be in /Applications for "Start at login" to work.
